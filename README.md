# Python App Launcher (Qt C++)

コマンドライン操作（ターミナル入力）に不慣れな元Windowsユーザー向けの、GUIベースのPythonアプリケーション起動・管理ランチャーです。

## 主な特徴

1. **完全GUI操作 (ターミナル不要)**:
   - Pythonスクリプト (`.py`, `.pyw`) の登録、起動、停止をボタン一つで実行。
2. **自動Python/仮想環境(venv)検出**:
   - スクリプトのあるフォルダ内の `venv` や `.venv` を自動認識。
   - システムPython (`/usr/bin/python3`) との切り替えも容易。
3. **リアルタイムGUIログモニター**:
   - ターミナルを開かなくても、標準出力 (stdout) と標準エラー (stderr) を色分けてリアルタイム表示。
   - ログ保存・一括削除に対応。
4. **ドラッグ＆ドロップ登録**:
   - ランチャー画面に `.py` ファイルをドロップするだけで簡単登録。
5. **設定の自動保存**:
   - 登録アプリ情報は JSON 形式で自動保存され、次回起動時に復元。

## 起動方法

### ダブルクリックで起動
`run.sh` をダブルクリック（または端末で `./run.sh`）でランチャーが起動します。

### 手動ビルド手順
```bash
mkdir -p build
cd build
cmake ..
make -j$(nproc)
./PythonLauncher
```

## サンプルアプリ同梱
初回起動時、動作テスト用のサンプルアプリが登録されます：
- **サンプル GUI アプリ (Tkinter)**: GUIウィンドウが正しく起動するかテスト
- **サンプル CLI ツール**: リアルタイムで進行状況ログが出力されるかテスト
